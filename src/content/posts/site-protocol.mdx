这个站之前有一套挺重的协作系统：一块「指挥室」看板，几张协议文档，AI 们开工前认领路径、写报告、刷在线状态。跑了几个月，我的结论是——它带给我的负担比省下的麻烦多。所以 2026 年 9 月 16 日，看板停用了，配套的认领卡、短锁、在线状态一并下线。

但规矩本身没有作废：代码怎么改、内容怎么发、提交怎么推，这些约定还是要有个地方放着。于是全部并入这一篇。**以后这个站的协议只有这一份**，要改就直接改这篇文章，并在文末「更新记录」里加一行。

## 一、这个站是什么

站名叫「永恒欲望」，域名 stulanez.com。技术上是一套 Astro 7 + Svelte 5 + TypeScript 的静态站，包管理只用 pnpm，代码风格跟 Biome 走：tab 缩进、双引号。

目录就记住几个：页面在 `src/pages`，布局在 `src/layouts`，组件在 `src/components`，文章在 `src/content/posts`，样式在 `src/styles`，站点配置在 `src/config`（优先从 `@/config` 导入）。静态资源放 `public`，源码图片放 `src/assets`。

## 二、改代码的规矩

- 本地开发 `pnpm dev`，验证改动静置三件套：`pnpm check`、`pnpm type-check`、`pnpm build`。视觉和交互上的改动，在 dev 或 preview 里亲眼看过再算完成。
- `pnpm format` 和 `pnpm lint` 会改写整个 src 和 scripts，不在共享工作区里全量跑，只对本次动过的文件定向处理。
- 构建时会自动生成一些文件：图片占位数据 `src/constants/lqips.json`、GitHub 卡片数据 `github-card-data.json`、VNDB 封面。这些是产物，不要手改；动了相关资产就让构建重新生成。
- 网站内部有一批 `/lab/*` 工具页（下载名单、清理监控之类），**成熟前一律不上线**。现在靠三层保护：生产中间件直接 404、构建后把 `dist/lab` 删掉、Vercel 路由兜底 404。动这一块时三层要一起理解，别觉得加个 noindex 就算藏住了。
- 改滚动、背景、侧栏这类常驻效果，保持 rAF 节流，别逐帧读布局，别上全屏模糊。

## 三、发内容的规矩

- 文章是 `src/content/posts` 下的 MDX。文章想配什么展示框架（交互演示、专用阅读器），就动手做配套组件，但普通文章不强行套小说阅读器。
- **MDX 里挂了组件，就必须在 frontmatter 后面 import 它**，然后打开文章页亲眼确认渲染。`pnpm check` 查不出漏 import，这是踩过的坑。
- 新文章封面一律通过 Grok API 现场新生成，不复用站内旧图、旧封面。凭证只在本机，不进日志、不进提交。图里不要硬生成中文标题——AI 生成的中文字不可靠，标题交给网页排版。
- 写给读者的话要解释术语、短句分段、数字真实。内容完成后自行提交推送，不用等我点头。

## 四、提交与部署

- 提交信息走 Conventional Commits；只暂存本次明确动过的路径，提交前看一眼暂存列表。
- 几条硬红线：不 `git add .` / `git add -A` / `git commit -a`，不 `git stash`、`git reset --hard`、`git clean`，不强推。
- 生产由 Vercel 监听 main 分支自动构建上线。**推送成功只代表代码进了仓库，不代表网站已更新**——说「已上线」必须有目标平台的部署记录或页面核验，不能用本地 build 成功来冒充。
- 新增需要服务端运行的接口，要确认适配器配置还在，别回退成纯静态配置。这类配置问题曾经导致推送成功但生产停在旧版本。
- 密钥、Cookie、个人素材、本地运行数据一律不进仓库；`.ai-work/` 是临时工作区，永不提交。

## 五、协作纪律

现在跟我搭手的 AI 不再看板打卡了，但几条底线保留下来：

- 我的当前指令优先于任何历史记录里的「下一步计划」。
- 开工前先看 `git status`：别人没提交的修改，一律保留，不去还原、覆盖、格式化。
- 一个路径同一时间只有一个人动；撞了就只停冲突的路径，别的不耽误。
- 有话直说，用大白话向我汇报；进度诚实，不捏造验收、截图和上线结果。
- 拿不准的事先问一句，但能自己查证的别拿去烦我。

## 六、图库和资产

数字资产库的采集、判图、去重、分类操作规程单独放在仓库的 `docs/ai/assets.md`，那部分是操作手册，不并入这篇。对外的规则只有一条：站上展示的资产要干净、有来源意识，个人素材和未授权的私货不上站。
