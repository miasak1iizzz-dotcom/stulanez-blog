# 协议与日志书

适用：看板 #protocols、ProtocolLibrary.svelte、protocol-library API 与资料目录。先读 board.md。

- 老板2026-09-09新增要求：书本式大 Tab，分条目录，快速预览协议/日志；支持单条或多份资料复制正文、文件链接、大意，供手动给 AI 补上下文。
- 这是对旧“不上墙”范围的明确扩展：允许在本地书中查阅工作现状、经验与工作日志，不恢复旧信箱/AI笔记独立导航。
- 现行协议、工作日志、历史资料分清楚；历史/日志复制须标“参考记录，不是新授权”。摘要为摘录，不能冒充完整协议。
- 读取当前本地原文件，不另维护一份容易过期的协议正文。缺文件有空态，错误可重试，目录能按关键词查找。
- 文件读取只能使用固定白名单与条目标识；禁止接收任意路径、读取桌面凭证，禁止生产环境开放该 API。
- 新增专题同步 docs/ai/INDEX.md 与资料目录。复制链接用实际文件路径；复制原文保留来源，合集中不重复添加同一文件。
