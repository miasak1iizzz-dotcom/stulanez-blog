# 等你过目与反馈

适用：inbox.json、卷宗翻页、反馈输入框/复制指令。先读 board.md。

- 只放需老板推进的验收、拍板、资源、必要跟进；AI 可决定的琐碎事项不占队列。
- pages 分页，必含「我替你先验了一遍」和「我的建议」；先准备可审结果再请求处理。
- 每页≤3段，大白话和具体数字；分清已验证与不确定，建议有方向有理由。
- 老板处理后 resolved；条件解除清理旧等待，不重复索要已有资源。
- 反馈可一键复制，带卷宗/任务标识和专题协议入口，新对话知道写回哪里。
- **草稿不得因刷新、HMR、切换详情丢失**。改 DOM/标识需检查 Layout 的 sessionStorage 保存恢复，不能只验外观。
- 按改动验证翻页/复制/处理、刷新后恢复；不重测无关 Tab。

来源：看板 v2 卷宗制、2026-09-07“看板·草稿保护”记录。
